Entry for the make.fun bounty **"Laugh Track: The Crypto Trading Joke"** (slug `u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a`).

## The entry

> I told the group chat I was diamond-handing, then quietly sold while typing "HODL" with my other hand.

A one-line joke about crypto trading life: the setup is the public diamond-hands bravado in the group chat, and the punchline is the private sell happening at the very same moment — the other hand still typing "HODL".

## How it works

`main.ts` (Node.js standard library only, no dependencies, no network) writes the joke as a single line of plain ASCII text to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline.

Run it with:

```sh
node main.ts
```
